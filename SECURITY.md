# Security policy

Cairn `v0.7.10` is the current stable source release. There is no long-term
support policy yet.

## Report a vulnerability

GitHub private vulnerability reporting is the intended disclosure channel and
must be enabled as part of publishing this repository. Once it is enabled,
please report suspected vulnerabilities through the
[private advisory form](https://github.com/veridian69/cairn/security/advisories/new).
Include the affected version or commit, the deployment shape, reproduction
steps, impact and any suggested mitigation. Do not include credentials,
private memory contents or other secrets.

Do not open a public issue for an undisclosed vulnerability. Ordinary
bugs and hardening suggestions that do not disclose a vulnerability may use
the public issue tracker.

This repository does not publish a Cairn container image. A report about an
image should identify who built it, the source revision and the resolved image
digest.
