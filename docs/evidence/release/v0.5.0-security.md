[FalkorDB recommends the server-only image for production](https://docs.falkordb.com/operations/docker),
but neither checked stable variant removes the fixable findings. Nightly
images were not selected. Cairn accepts the owned build, publication, source
availability and maintenance responsibility of the selected derivative.

**Accepted release direction:** ship Cairn’s maintained, server-only derivative.
The image is pinned by OCI index digest in the installer and deployment lock.
Build inputs, source/licence material and replacement policy live in
[the runtime release directory](../../../deploy/falkordb/README.md).
Publication remains a separate step. Disposable Docker installations on reference
have exercised both the official baseline and patched runtime with semantic
retrieval and Attic, including authorised real-provider calls and restart checks.

## Upstream remediation submitted

[FalkorDB PR #2838](https://github.com/FalkorDB/FalkorDB/pull/2838) fixes a
reproduced Docker shell failure-handling bug on the supported `4.20` branch:
an optional cleanup fallback could hide a required package upgrade failure.
The regression passes all 16 scenarios; independent review passed. No claim
is made that this failure mode caused the published image findings.

A fresh local amd64 server runtime passed graph persistence checks and has
zero fixable HIGH/CRITICAL findings in the same database, with 36 HIGH findings
without vendor fixes. It retains the exact published 4.20.4 module. It is a
maintained Cairn release candidate; registry publication is pending.

The full image also needs the browser fixes published: Next.js is fixed in
upstream staging and the exact Sharp update is already tracked by
[browser PR #2091](https://github.com/FalkorDB/falkordb-browser/pull/2091).
Cairn’s server-only derivative does not include these browser packages.

## Corresponding-source acceptance

The accepted source archive is pinned in

pinned Redis archive, 73 runtime binary packages mapped to 53 exact Debian

image must be made available together when this candidate is published.
