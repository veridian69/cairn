# Cairn v0.7.10

`v0.7.10` (`drystane-cairn==0.7.10`) corrects installation findings from the
v0.7.9 and v0.7.10 blind acceptance runs. Garden remains Linux-only and is not supported on
macOS.

- Garden TLS generation rejects loopback endpoint names before generating files.
- Managed Garden accepts its configured public endpoint through Kubernetes
  port-forwards and TLS ingress while rejecting unrelated HTTP Host values.
  Installer verification now checks the public HTTP authority as well as TLS.
- Installation docs clarify harmless kubectl namespace warnings and expected
  first-read `evidence_pending` retries.
- Kubernetes probe failures identify image-pull problems as well as recognised
  gateway failures, without replaying untrusted container messages.
- Kubernetes Garden supports local builds staged into containerd, without a
  registry. Its immutable staging receipt binds exact images and node identities;
  cache probes and storage placement checks run before installation proceeds.
- Gateway removal waits for transient workloads and excludes historical Events
  from its final inventory. New sites can create a local GitOps record repository.
- Garden TLS generation accepts an optional listener port, and adapter builds
  carry the release version. Installer output and Docker provenance labels are
  clearer.
- Adapter verification instructions include creating the working profile and
  installing the host-side `a2a` binary for Docker and Kubernetes deployments.
- Semantic Kubernetes instructions put shared-gateway readiness before expensive
  runtime-image preparation.

The catalogue schema, Attic format and versioned REST and MCP contracts are
unchanged. This release ships source and local build recipes, not container
images.
