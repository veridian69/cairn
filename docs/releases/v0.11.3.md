# Cairn v0.11.3

`v0.11.3` (`drystane-cairn==0.11.3`) is a patch release on v0.11.2. v0.11.2
was not published on its own, so this is the first published release since
v0.11.1 and carries its changes; read the [v0.11.2 notes](v0.11.2.md) first.
v0.11.3 fixes one gap in the contradiction confirmation that v0.11.2
introduced. The REST contract, catalogue schema, Attic format, client
commands and locked dependencies are unchanged, and no rebuild is required.
This release ships source and local build recipes, not container images:
`CAIRN_IMAGE` and `CAIRN_EDGE_IMAGE` in `deploy/images.lock` name local
source-build tags. Garden remains Linux only.

## Fix: contradictions are confirmed at edge batch size 1 too

**What failed.** The v0.11.2 notes say that a contradiction declared by the
judge is confirmed by a second call before a graph fact is ended. With
`graphiti.edge_batch_size: 1` that was not so. At that size Cairn installed
none of its edge-judging layer, Graphiti called the provider directly, and a
declared contradiction ended a graph fact on one judgement, as before
v0.11.2. The default of 10 was not affected. v0.11.2 was not published, so no
published version had the confirmation without this fix.

**The fix.** The layer is now installed at every batch size. At size 1
nothing is combined: each item is asked on its own, with the question
Graphiti would have asked, and a contradiction it declares is confirmed like
any other. This is the path an item already took whenever it ended up alone
in a batch at a larger size.

**Consequence.** No setting bypasses Cairn's edge-judging layer any more.
Size 1 was never documented as a bypass. The layer's check of the
graphiti-core version now also runs at size 1; Cairn already refused to
start on any other version than the locked one at every size, so no start
that worked before fails now.

**Price at size 1.** One further call on the medium model for each item that
declares a contradiction, as at every other size.

Not measured: this path against the live provider at size 1 specifically.
The measurements of the single call with confirmation in the v0.11.2 notes
are of the same code path.
