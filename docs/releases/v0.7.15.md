# Cairn v0.7.15

`v0.7.15` (`drystane-cairn==0.7.15`) is a patch release on v0.7.14. It tightens
the secret screen so that ordinary status facts are no longer refused, fixes a
first-open failure in Garden's memory store, and makes the migration overlay
refuse malformed ruled timestamps before it writes a plan. Cairn's REST, MCP and
memory contracts, catalogue schema and Attic format are unchanged. This release
ships source and local build recipes, not container images: `CAIRN_IMAGE` and
`CAIRN_EDGE_IMAGE` in `deploy/images.lock` name local source-build tags.

## Secret screen

**Labelled words only (`contextual-entropy`).** After UUID excision, a
word-shaped candidate consists of lowercase, uppercase or title-case ASCII
tokens, each containing at most twelve letters optionally followed by digits,
or standalone digit tokens, joined by `-`, `_` or `/`. Runs consisting only
of hex digits and joiners are excluded. Such candidates fire only when a
keyword labels them: a `:` or `=` gap, the word `is` or `was`, or a run-start
keyword immediately followed by `-`, `_` or `/`. Unlabelled candidates pass,
including `docs/operations/P4-Window-Cutover` beside a keyword.

**File names pass.** A raw candidate followed directly by a one-to-eight
ASCII alphanumeric dot extension is exempt whether labelled or not. Each
`=`-separated piece must consist of case-consistent tokens with optional
trailing digits, or standalone digit tokens, joined by `-`, `_` or `/`;
none may consist only of hex digits and joiners. File tokens have no
twelve-letter cap. `credential=relay-credential-alpha-host.json` passes.

**Still refused.** Candidates outside the word grammar retain the keyword
window test, unless file-exempt. Examples include `W10-FREEZE-7c41ab` and
internally mixed-case runs. Hex-only runs remain non-exempt, including
`4c1d90eb27f5a3608b9e2d47f0a6c853.json` near a keyword. Labelled word-shaped
candidates without a valid file extension still fire, including
`password: Winter-Meadow-Copper-Lantern`.

**Accepted residuals.**

- Unlabelled word passphrases pass, including `the vault password, for the
  record, winter-meadow-copper-lantern`.
- A digit directly after a run-start keyword removes that prefix label:
  `password1-winter-meadow-copper-lantern` and
  `token2-abcdef0123456789-ABCDEF0123456789` pass. Interleaved hex tails such
  as `token2-4c1d90eb27f5a3608b9e2d47f0a6c853` still fire.
- Valid file extensions exempt labelled passphrases too:
  `credential: winter-meadow-copper-lantern.txt` and
  `password: Winter-Meadow-Copper-Lantern.txt` pass. Random lowercase,
  uppercase or title-case file tokens also pass; internally mixed-case
  tokens remain non-exempt.

Agents should retain reword-to-avoid guidance for candidates outside these
exemptions. Policy identity stays `cairn.secret/v1`. The change only narrows
what is refused, so no rescan of data already in custody is needed.

## Garden memory store

The memory store retries `SQLITE_BUSY` when opening its first connection,
within a five-second budget. This avoids immediate first-open failure when
concurrent connections contend while switching a fresh database to WAL.

## Migration tooling

**`cairn_migrate overlay` timestamps.** A ruled turn whose source `created_at`
is not a catalogue timestamp (`YYYY-MM-DDTHH:MM:SS.ffffffZ`) now refuses the
rulings file as `rulings_invalid` before any plan is written, rather than
failing later at `apply`. Only the canonical six-digit form is accepted.

## Operator and evaluation scripts

**`--falkordb-image` for the semantic evaluator.** `scripts/evaluate_semantic_memory.py`
accepts `--falkordb-image REF` to override the FalkorDB image in
`deploy/images.lock`. The override takes a digest-pinned maintained image, or
`cairn.local/falkordb-runtime@sha256:<64 hex>` for a locally built runtime. The `cairn.local` form is accepted only through the explicit
override, not from `deploy/images.lock`; the all-zero placeholder digest remains
refused.

## Test and CI

- The public CI split pin is updated for the sanitised Makefile.
- A projection test drains its cancelled call before the loop stops. This is a
  test-only fix with no runtime change.
