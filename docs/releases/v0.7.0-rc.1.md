# Cairn v0.7.0-rc.1

`v0.7.0-rc.1` (`drystane-cairn==0.7.0rc1`) brings the shared Garden conversation service and guided Kubernetes installation into the public distribution. It builds on v0.5.0-rc.4 without changing the catalogue schema, Attic format or versioned REST/MCP contract.

## Changes

- Optional managed Garden deployment through `cairn-install`, with participant enrolment, separate storage, and resume, rollback and removal workflows.
- Garden’s Go source, CLI, terminal UI, MCP gateway and coding-agent attention adapters are included in the source distribution checkout.
- Guided Kubernetes installation, including retained deployment state, owned port-forwarding and optional semantic configuration.
- Explicit Garden platform checks: **Garden is not supported on macOS. Run Garden on Linux.** Cairn’s macOS catalogue-memory and Attic support remains available.
- Verified offline containerd loading preserves the maintained FalkorDB index digest for Kubernetes. See the [node loading procedure](../../deploy/falkordb/README.md#kubernetes-with-an-offline-containerd-image-store); an anonymous GHCR pull is not claimed.
- Interrupted Kubernetes acceptance runs now report failure and clean up only their owned disposable cluster.
- Python resource ownership fixes for database connections, subprocesses, sockets and HTTP responses. Resource warnings now fail the test suite. The upstream Graphiti/Pydantic deprecation remains visible.

## Installation

Use a trusted checkout of this tag, Python 3.12–3.14 and uv 0.12.14, then run `./cairn-install`. Follow the [installation guide](../install.md) and [managed Garden guide](../operations/managed-garden.md). Garden is a separate Go binary and is not part of the Cairn Python wheel.

Linux semantic installations use the maintained FalkorDB runtime `v4.20.4-cairn.1`. The [offline-image procedure](../../deploy/falkordb/README.md#install-the-maintained-offline-image) explains loading the image with its matching corresponding-source archive and notices. No new registry digest or signed Cairn container image is claimed.

## Acceptance and boundaries

This is a Gitea-only testing candidate. GitHub publication is deferred. Source checks pass (6,834 tests, 138 skipped), as do Garden checks, race tests and synthetic Cairn integration. Candidate artefact results are recorded with the Gitea release.

Fresh hosted Intel and Apple Silicon macOS acceptance has not run for this candidate. Prior RC4 macOS acceptance does not certify these new artefacts; local Garden refusal regressions pass.

Garden runs on Linux. macOS semantic search remains disabled in the guided installer; remote semantic search, macOS 12 and an actual logout/login cycle remain unvalidated. An existing Garden conversation is not automatically a Cairn memory record: Cairn scope, grants and evidence rules continue to apply separately.
