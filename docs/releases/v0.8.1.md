# Cairn v0.8.1

`v0.8.1` (`drystane-cairn==0.8.1`) is a patch release on v0.8.0. v0.8.0
was tagged but not published on its own, so this is the first published release
to carry its changes; read the [v0.8.0 notes](v0.8.0.md) first. v0.8.1 fixes
one gap in the published source tree. The Cairn server and Garden are unchanged
apart from the version identity: the REST and MCP contracts, catalogue schema
and Attic format are as in v0.7.18. This release ships source and local build
recipes, not container images: `CAIRN_IMAGE` and `CAIRN_EDGE_IMAGE` in
`deploy/images.lock` name local source-build tags.

## The published tree passes its own `make check`

**What failed.** The v0.8.0 source tree includes
`scripts/backup/backup_common.py` and `scripts/backup/garden_common.py`, which
the wheel and the Cairn image build need, but not the `scripts/backup/ruff.toml`
that excludes them from lint. `make check` in that tree therefore stopped at
`ruff check`.

**What changed.** `scripts/backup/ruff.toml` is now published. A policy test
requires every `ruff.toml` that governs published Python to be published with
it. One installer test now uses the documentation address `192.0.2.10`.

**Price and bound.** The two helpers are unchanged and still excluded from
lint; bringing them to the repository's lint rules is separate work. No runtime
behaviour changes.

## Upgrade

From v0.7.20, follow the [v0.8.0 upgrade](v0.8.0.md#upgrade). From v0.8.0, no
action is needed: rebuilding is optional, because only the version identity
changes.
