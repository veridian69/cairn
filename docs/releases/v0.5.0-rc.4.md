# Cairn v0.5.0-rc.4

`v0.5.0-rc.4` (`drystane-cairn==0.5.0rc4`) is a release candidate following
[RC3](v0.5.0-rc.3.md). RC3 remains unchanged. RC4 retains the same dependency
versions, catalogue schema, Attic format and maintained FalkorDB image
(`v4.20.4-cairn.1`). No new database migration is introduced.

## Changes

- macOS `blitz` now checks mount boundaries inside the owned instance tree,
  rather than resolving every mounted volume. Unrelated stale volumes are no
  longer probed by this guard. Mounted directories and automount triggers are
  refused before opening their contents; the scanner does not follow symlinks.
- Hosted jobs allocate runners only for public repositories. Private source
  checks run locally; reviewed snapshots pass through the sanitised exporter
  before public validation. Mac acceptance is manual and uses standard Intel
  and Apple Silicon runners.
- Offline-image instructions use a stable section anchor. Older RC3/RC4
  anchors remain available, and the installation guides link to the loader.

The tests include a real disk image mounted inside a disposable instance,
which the guard refuses while preserving its contents, plus non-empty-directory
and filesystem-root checks. The lifecycle exercises launchd, memory corrections
and disagreements, exact Attic bytes, restart, rollback/resume, ownership
protections and blitz. Subsequent release changes are documentation and an
explanatory code comment only; the tested runtime behaviour is unchanged.

The committed public export passed local `make check`: **6,668 passed,
137 skipped, 93% coverage**. `pip-audit` reported no known vulnerabilities
in the locked Python dependencies.
Independent review verified the native scanner and the export boundary.

## Installation and downloads

Use a trusted checkout of tag `v0.5.0-rc.4`, host Python 3.12–3.14 and uv
0.12.14, then run `./cairn-install`. The release assets include the Python wheel,
source distribution and `SHA256SUMS`.

Linux semantic installations also need the maintained FalkorDB runtime:

- [Offline image](https://github.com/veridian69/cairn/releases/download/v0.5.0-rc.4/cairn-falkordb-v4.20.4-cairn.1.tar).
- [Matching corresponding source, build inputs and notices](https://github.com/veridian69/cairn/releases/download/v0.5.0-rc.4/cairn-falkordb-v4.20.4-cairn.1-source.tar.gz), available at no charge alongside the binary.
- [Checksums](https://github.com/veridian69/cairn/releases/download/v0.5.0-rc.4/SHA256SUMS).

Follow the [archive-loading procedure](../../deploy/falkordb/README.md#install-the-maintained-offline-image),
which requires Docker's containerd image store. The FalkorDB binary and source
archives are unchanged from RC3. No GHCR publication or signed Cairn container
image is claimed.

## Boundaries

macOS supports local catalogue memory and Attic, including per-user launchd
background operation. Semantic search is disabled in the Mac installer;
connecting a Mac to remote FalkorDB is not yet validated. macOS 12 and an actual
logout/login cycle remain untested. The versioned REST/MCP contract and
server-enforced scope and evidence guarantees are unchanged.
