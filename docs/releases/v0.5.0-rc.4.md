# Cairn v0.5.0-rc.4

`v0.5.0-rc.4` (`drystane-cairn==0.5.0rc4`) is a release candidate following
[RC3](v0.5.0-rc.3.md). It retains the same dependency versions, catalogue schema,
Attic format and maintained FalkorDB image (`v4.20.4-cairn.1`). No new database
migration is introduced.

## Changes

- macOS `blitz` mount-boundary validation is being revised to inspect only the
  owned instance tree, avoiding filesystem probes of unrelated stale volumes.
- Hosted checks run only in the public distribution repository. Mac acceptance
  is manual and uses standard Intel and Apple Silicon runners. Private source
  checks run locally.

## Acceptance

RC4 verification is in progress. RC3's Mac results are historical evidence;
they do not establish that the revised deletion guard has passed on a Mac.
The candidate must pass local checks, independent review and the public Mac
acceptance matrix before publication.

## Scope and installation

Use `./cairn-install` from a trusted candidate checkout. macOS supports local
catalogue memory and Attic, including per-user launchd background operation.
Semantic search is disabled in the Mac installer; connecting a Mac to remote
FalkorDB is not yet validated. macOS 12 and actual logout/login remain untested.

Linux semantic installations use the maintained offline FalkorDB image and its
matching corresponding-source bundle, with the archive-loading procedure in
[the runtime guide](../../deploy/falkordb/README.md). No GHCR publication or
signed Cairn container image is claimed.
