# Cairn v0.7.9

`v0.7.9` (`drystane-cairn==0.7.9`) is a corrective stable source release for
the v0.7 line. It includes the guided disposable, native, Docker and Kubernetes
installation modes, optional semantic retrieval, and managed Garden on Linux.
Garden is not supported on macOS; macOS supports catalogue memory and Attic in
foreground or native LaunchAgent modes.

## Reliability corrections

- Agent workers now retry a failed deduplicated reply publication before
  processing or checkpointing later inbox items. Cancellation leaves the
  failed sequence uncheckpointed so restart replay remains safe.
- Configuration loading rejects `defaults.context_window` values outside
  `1..10000`, preventing invalid history bounds from reaching the daemon.

## Installation and runtime

- `cairn-install` documents and executes all four installation modes, including
  lifecycle status, resume, rollback and removal.
- Semantic native, Docker and Kubernetes installations use an operator-built
  FalkorDB runtime made from the pinned recipe. Cairn does not distribute or
  publish a FalkorDB image.
- Kubernetes checks can fetch the pinned `kubectl` automatically, and can stage
  reviewed locally built Cairn and FalkorDB images onto eligible nodes.
- Managed Garden participates in the installed instance lifecycle on Linux.
  `scripts/generate-garden-tls` creates a private CA, a validated server
  certificate chain and a complete installer-ready `garden.json` without
  overwriting existing material.

## Publication boundary

This release publishes source to GitHub and Gitea. It does not publish Cairn or
FalkorDB container images and does not push anything to GHCR. The image tag in
`deploy/images.lock` names a local build; operators retain and record the digest
of the image they build or place in an internal registry.

The catalogue schema, Attic format and versioned REST and MCP contracts are
unchanged from v0.7.8.
