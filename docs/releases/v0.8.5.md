# Cairn v0.8.5

`v0.8.5` (`drystane-cairn==0.8.5`) is a patch release on v0.8.4. Neither
v0.8.3 nor v0.8.4 was published on its own, so this is the first published
release since v0.8.2 and carries their changes; read the
[v0.8.3 notes](v0.8.3.md) first, then the [v0.8.4 notes](v0.8.4.md). v0.8.5
upgrades `zlib1g` in the runtime image. Nothing else changes apart from the
version identity: the REST and MCP contracts, catalogue schema and Attic format
are as in v0.8.2. This release ships source and local build recipes, not
container images: `CAIRN_IMAGE` and `CAIRN_EDGE_IMAGE` in `deploy/images.lock`
name local source-build tags.

## Runtime image: `zlib1g` for CVE-2026-76844 and CVE-2026-85091

The `python:3.14.7-slim-trixie` base ships `zlib1g`
`1:1.3.dfsg+really1.3.1-1+b1`. On 7 November 2026 Debian published
`1+deb13u1`, which fixes two HIGH advisories, CVE-2026-76844 and
CVE-2026-85091, and the image gate rejected the v0.8.4 image on them.
`zlib1g` joins the runtime stage's `--only-upgrade` list beside `apt`, which
v0.8.3 added. Scanner thresholds and image pins are unchanged.

## Upgrade

From v0.8.2, follow the [v0.8.3 upgrade](v0.8.3.md#upgrade). From v0.8.3 or
v0.8.4, rebuild the image; no other action is needed.
