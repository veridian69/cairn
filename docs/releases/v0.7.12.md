# Cairn v0.7.12

`v0.7.12` (`drystane-cairn==0.7.12`) hardens the local MCP relay, adds worker
startup readiness to Garden adapters and refreshes two dependencies. There was
no `v0.7.11` release. Garden remains Linux-only and is not supported on macOS.

- The `cairn-mcp` STDIO relay keeps its legacy listener stream alive across
  Cloudflare stream resets. It reconnects with bounded backoff, sending the last
  delivered event ID when it has one; it never replays a JSON-RPC call. A terminal STDIO
  error is also appended to `$XDG_STATE_HOME/cairn-mcp/stdio.log`.
- Re-running `cairn-mcp/scripts/install-user` restarts a running relay onto the
  newly installed binary.
- OpenCode client configuration for the relay is documented, including the
  native Windows build. OpenCode uses the existing Claude or Codex host-workflow
  skill package; there is no separate OpenCode provider.
- `a2a doctor --readiness` reports a bounded, read-only startup readiness
  observation for a Garden worker. See `a2a/docs/readiness.md`.
- `make -C a2a integration` also runs Garden against a disposable real Cairn over
  HTTPS, trusting the fixture's certificate authority and refusing an unrelated
  one.
- `a2a agent add` refuses an existing configuration it cannot read or parse, or
  whose `defaults.context_window` is out of range, instead of replacing it.
- Generated Garden TLS certificates are backdated by ten minutes to tolerate
  clock skew between hosts.
- `pyjwt` 2.15.1 and `urllib3` 2.8.0 clear dependency-audit advisories.
- The README's lead demo is real work on deepdiff issue #550, with its harness,
  verifier and full technical transcript.

The catalogue schema, Attic format and versioned REST and MCP contracts are
unchanged. This release ships source and local build recipes, not container
images.
