# Cairn v0.7.0-rc.4

`v0.7.0-rc.4` (`drystane-cairn==0.7.0rc4`) corrects the fresh-clone
installation defects found during blind rc.3 acceptance. It retains rc.3's
operator-built FalkorDB runtime, managed Garden and four guided Cairn install
modes. It does not change the catalogue schema, Attic format or versioned
REST/MCP contracts.

## Installation corrections

- Kubernetes preloaded-image preflight now waits up to 120 seconds for kubelet
  to report a just-staged image digest before failing, and tolerates incomplete
  image-status entries while kubelet refreshes them. A timeout names the node
  and gives shell-safe inspection and resume commands.
- Garden TLS verification now reports the endpoint hostname and the underlying
  OpenSSL reason. The Garden guide specifies the required CA constraints, key
  usage, leaf DNS SAN and `serverAuth` extended key usage.
- The guided Kubernetes path builds the Cairn tag read from
  `deploy/images.lock`, names the required namespace label, explains kubelet's
  image-report delay and links the manual namespace preparation commands.
- Kubernetes semantic prerequisites now name the owner-controlled site GitOps
  checkout required to retain and commit the shared gateway record.
- FalkorDB node staging now states that SSH is always used, including when the
  operator checkout is already on the single Kubernetes node.
- The public landing page names all four installer modes. Garden remains
  unsupported on macOS.

## Publication and acceptance boundary

This is a **Gitea-only** release candidate. Do not publish it to GitHub. The
release contains the FalkorDB build recipe and staging tools, but no FalkorDB
image archive, source bundle or GHCR publication. Operators build and retain
their own reviewed database runtime.

The rc.3 blind run completed disposable, native, Docker and Kubernetes Cairn
installations and a managed Garden installation. Rc.4 requires a new blind run
from a fresh clone because it changes installer preflight behaviour, diagnostics
and installation instructions.
